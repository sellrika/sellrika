# Security

## Report a security problem

Please do not open a public issue for a security problem.
A public issue shows the problem to everyone before it is fixed.

Write to [support@sellrika.com](mailto:support@sellrika.com) instead.

Tell us:

- What the problem is, and what someone could do with it.
- The steps to see it.
- The version or the commit you tested.

## What happens next

- We answer within 3 working days.
- We tell you when the fix is out.
- We name you in the release notes, when you want that.

Please give us time to fix the problem before you write about it in public.

## Which version gets fixes

Only the newest version on the `main` branch.
