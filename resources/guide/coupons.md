# Coupons

A coupon is a discount code. A buyer types it at the online checkout, or a cashier types it at the till.
The page is in the sidebar under **Sales › Coupons**. Only admins see it.

## How to make a discount code

1. Open **Sales › Coupons**.
2. Press **Add coupon**.
3. Type the **Code**. Use 3 to 30 letters, numbers, `-` or `_`. Or press the small button inside the box (**Generate a random code**) to get a random code.
4. Type a **Description** if you want. The customer sees it when the code applies.
5. Under **Discount**, pick one kind:
   - **Percentage off**. Type the number in **Percentage**. You may also set a **Maximum discount** in money.
   - **Fixed amount off**. Type the amount in **Amount off**.
   - **Free delivery**. The delivery fee is not charged. There is no number to type.
6. Press **Add coupon** at the bottom.

Only the code and the discount are needed. Everything else is optional.

## How to set limits on a code

Open the code (press its row in the list) or set these while you add it.

Under **Validity and limits**:

1. **Starts on** and **Ends on**: the first and the last day the code works. Both days count. Leave **Ends on** blank for no end date. The days follow the shop's time zone.
2. **Minimum order**: the cart must reach this amount. It counts the items only, before delivery.
3. **Total uses**: how many times the code may be used in all. Blank means unlimited.
4. **Uses per customer**: how many times one customer may use it. Blank means unlimited. A customer is known by their email.

Under **Applies to**:

1. Keep **All products**, or pick **Specific products or categories**.
2. Pick the **Categories**, and search and tick the **Products**.
3. An item counts when it is one of these products or in one of these categories. The discount is worked out on those items only.

To make a code for some customers only:

1. Find **Only for these customers**.
2. Type one email per line.
3. The code then works only for these email addresses.

Press **Save** (or **Add coupon** for a new code) when you are done.

## How to change a code

1. Open **Sales › Coupons**.
2. Press the row of the code. The **Edit** dialog opens.
3. Change what you need.
4. Press **Save**.

## How to switch a code off

1. Press the row of the code.
2. Switch **Active** off.
3. Press **Save**.

The code stops working at once. Its history stays. Switch **Active** on again to use it again.

## How to delete a code

1. Press the row of the code.
2. Press **Delete** at the bottom left.
3. Press **Delete** again to confirm.

Customers can not use the code any more. Orders that already used it keep the code in their history.

## How to copy a code

1. Find the code in the list.
2. Press the copy button next to the code.
3. Paste it into your message to the customer.

## How to see how a code is doing

The four cards above the list add up all codes of the shop: **Times used**, **Total discount given**, **Sales with a code** and **Average discount**.

In the list, each code shows:

- **Discount**: what it takes off.
- **Conditions**: its limits, in short.
- **Valid**: its dates.
- **Used**: how many times it was used, and the limit if there is one. Press the **Used** heading to put the most used codes first.
- **Status**: **Active**, **Scheduled** (not started yet), **Expired**, **Used up** or **Off**.

To see every order that used one code:

1. Press the history button (the clock) at the end of the row.
2. You see **Times used**, **Total discount given** and **Last used**.
3. Below is the list of orders: date, order, customer, **Order total** and the discount.
4. Press an order to open it.

## How a buyer uses a code online

1. The buyer goes to the checkout of your online store.
2. In the order summary, they type the code in the **Discount code** box.
3. They press **Apply**.
4. The discount shows in the summary. If the code does not work, a message under the box says why.
5. The buyer finishes the order as usual.

## How a cashier uses a code at the till

1. Add the items to the cart on the **Sell** screen.
2. Press **Discount** in the cart, under the subtotal.
3. Under **Discount code**, type the code.
4. Press **Apply code**.
5. The cart shows the code and what it takes off. Finish the sale as usual.

To take the code off again, press the code in the cart and then **Remove**.

## Good to know

- Only admins can open the Coupons page. Every role can type a code at the till.
- One code per order. Codes can not be combined.
- At the till, a sale has one discount. A code replaces a discount typed by hand, and the other way round.
- A **Free delivery** code does not work at the till. There is no delivery there.
- Codes for some customers only: online, the buyer must be signed in to the store with that email. At the till, add the customer to the sale first. The customer must have that email.
- **Uses per customer** needs an email too. At the till, add a customer with an email to the sale.
- The code is checked again when the buyer pays. If it was used up or ended in between, the checkout says so.
- When you void an order, its use of the code is given back.
- Buyers may type the code in small or big letters. Both work.
- For a wrong, ended, switched-off or used-up code, the buyer always sees the same message: "That code isn't valid".
- Two codes in one shop can not have the same name.
- Deleting a code can not be undone. Switch it off if you want to keep its history.
